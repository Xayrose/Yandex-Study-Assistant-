# Yandex Study Assistant v4.3.0

Расширение Chrome / Яндекс Браузера для Яндекс Учебника.

**Сайт и загрузка:** https://xayrose.github.io/Yandex-Study-Assistant-/

## Режим «Решить Авто»
1. Применяет локальные решатели информатики.
2. Если локального правила нет, автоматически отправляет текст задания и видимые элементы выбранному AI-провайдеру.
3. Заполняет распознанные поля и варианты ответа.
4. Использует стандартные кнопки проверки и перехода, ожидает обновления страницы.

Для AI fallback нужен API-ключ хотя бы одного сервиса: Gemini, Groq, OpenRouter, SambaNova или Cerebras. Интернет без API-ключа не предоставляет доступ к модели.

## Установка
1. Откройте сайт проекта и нажмите «Скачать расширение».
2. На странице загрузки нажмите кнопку создания ZIP.
3. Распакуйте архив.
4. Откройте chrome://extensions или browser://extensions.
5. Включите режим разработчика и нажмите «Загрузить распакованное».
6. Выберите папку extension.

## Ограничения
Проект не гарантирует решение абсолютно всех упражнений. Текстовые задания и стандартные формы поддерживаются лучше; задания на изображениях без alt-текста, canvas, сложный drag-and-drop и нестандартные интерактивные виджеты требуют отдельной реализации. При недостаточной уверенности расширение останавливается вместо случайной отправки.
