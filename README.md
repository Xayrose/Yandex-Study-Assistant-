# Yandex Study Assistant

Локальное расширение для браузера, которое автоматизирует часть типовых заданий Яндекс Учебника. Версия **3.4.0**, без нейросетей и внешних API.

**Сайт проекта:** https://xayrose.github.io/Yandex-Study-Assistant-/

**Разработчик:** [@Xayrose](https://t.me/Xayrose)

## Возможности

- Локальные решатели: системы счисления, единицы информации, информационный объём, алфавиты/кодирование и простая арифметика.
- Обнаружение стандартных полей ввода, radio, checkbox, select и кнопок подтверждения.
- Раскрытие блоков «Ещё», «Подробнее», «Развернуть» и похожих элементов.
- Запоминание признаков элементов управления между слайдами.
- Защита от повторных действий, остановка при неверном ответе и журнал действий.
- Настройки лимита шагов, запоминания элементов и автоматического раскрытия.

## Установка

1. Нажмите **Code → Download ZIP** в GitHub или скачайте архив проекта с сайта.
2. Распакуйте архив в отдельную папку.
3. Откройте страницу расширений:
   - Chrome: `chrome://extensions`
   - Яндекс Браузер: `browser://extensions`
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное**.
6. Выберите папку `extension`, внутри которой находится `manifest.json`.
7. Откройте или обновите вкладку Яндекс Учебника на `education.yandex.ru`.

Для обновления скачайте свежую версию, распакуйте её и нажмите кнопку обновления на карточке расширения либо удалите старую версию и загрузите новую папку.

## Как пользоваться

1. Откройте урок на `education.yandex.ru`.
2. Дождитесь появления панели **Yandex Study Assistant** внизу справа.
3. Нажмите **Решить Авто**.
4. Следите за статусом и журналом действий. При сообщении о необходимости проверки решите задание вручную.

## Настройки

Откройте меню расширения и выберите **Настройки**. Можно изменить максимальное число действий за запуск, включить/отключить запоминание элементов и автоматическое раскрытие дополнительных блоков.

## Ограничения

Это не универсальный решатель всех упражнений. Перетаскивание пар, сортировка, сложные таблицы, редакторы кода, задания на изображениях и canvas могут требовать знания внутренней структуры конкретного виджета. В неизвестных или неоднозначных случаях помощник останавливается и не должен угадывать ответ.

Работа автоматизации выполняется локально в браузере. При этом сам сайт Яндекс Учебника может загружать свои обычные сетевые ресурсы.

## Проверка

Требуется Node.js. Из корня репозитория выполните:

```bash
node tests/rules.test.js
```

## Структура

- `index.html` — сайт проекта и инструкция.
- `extension/` — готовая папка расширения для загрузки в браузер.
- `tests/` — тесты локальных правил.
