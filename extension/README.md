# Yandex Study Assistant v4.3.0

Расширение Chrome / Яндекс Браузера для Яндекс Учебника.

## Что изменилось в 4.3.0
- «Решить Авто» сначала использует локальные решатели, а для незнакомых форматов автоматически переключается на подключённый AI-провайдер.
- AI может заполнять несколько текстовых полей, выбирать radio/checkbox/option и обычные select.
- AI-запросы выполняются фоновым service worker Manifest V3, а не из контекста страницы.
- Поддерживаются стандартные кнопки и ссылки «Далее» / «Продолжение».
- Исправлен разбор составных выражений A/B/C с вводным текстом в той же строке.
- Исправлено сохранение ключа SambaNova.

## Подключение ИИ
Для AI fallback нужен хотя бы один API-ключ Gemini, Groq, OpenRouter, SambaNova или Cerebras. Просто доступ в интернет не предоставляет ключ к API нейросети.

1. Откройте меню расширения → «Настройки».
2. Добавьте API-ключ хотя бы одного провайдера и сохраните настройки.
3. Откройте задание на education.yandex.ru.
4. Нажмите «Решить Авто». Если локальные правила не распознали задание, расширение автоматически обратится к ИИ.

Ключи хранятся в локальном хранилище браузера. Текст задания и описания видимых элементов передаются выбранному AI-провайдеру. Не включайте личные данные.

## Поддержка
Локально решаются типовые задания на системы счисления, единицы информации, информационный объём, алфавиты/кодирование, арифметику, проценты, среднее, скорость и простую геометрию. Автоматический AI fallback работает с видимыми текстовыми полями, radio/checkbox/option и обычными select.

## Ограничения
Это не гарантированный решатель абсолютно всех упражнений. AI получает текст страницы, список видимых элементов и alt/aria-описания изображений, но не пиксельный скриншот. Задания на изображениях без текстового описания, canvas, сложные drag-and-drop, интерактивные схемы и нестандартные виджеты могут требовать отдельной реализации. Результат зависит от модели, API-лимитов и доступности провайдера. При низкой уверенности расширение останавливается вместо отправки случайного ответа.

Расширение не является официальным продуктом Яндекса.

## Установка
1. Распакуйте ZIP.
2. Откройте chrome://extensions или browser://extensions.
3. Включите режим разработчика.
4. Нажмите «Загрузить распакованное» и выберите папку extension.
5. Обновите вкладку Яндекс Учебника.
