# Yandex Study Assistant v3.4.0

Расширение Chrome / Яндекс Браузера. Работает локально, без ИИ и внешних API.

## Установка
1. Скачайте и распакуйте весь репозиторий.
2. Откройте `chrome://extensions` или `browser://extensions`.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное».
5. Выберите именно эту папку `extension`, где находится `manifest.json`.
6. Обновите вкладку урока на `education.yandex.ru`.

## Запуск
Откройте урок. Панель помощника появится внизу справа. Нажмите «Решить Авто». Если задача не поддерживается или ответ неоднозначен, расширение остановится.

## Локальные алгоритмы
Системы счисления, единицы информации, информационный объём, простые задачи на алфавиты/кодирование и арифметика.

## Ограничения
Перетаскивание, сортировка, сложные таблицы, редакторы кода, задания на изображениях и canvas могут не поддерживаться. Помощник не должен угадывать ответ.
