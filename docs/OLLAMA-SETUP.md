# Ollama: локальная модель для учебной помощи

> Это руководство описывает установку Ollama и ручную проверку/объяснение задач. В текущей версии расширения (4.3.0) Ollama напрямую не подключена; настройки сторонних AI-провайдеров в расширении не заменяются Ollama автоматически.

## 1. Установить Ollama

- Официальная загрузка: https://ollama.com/download
- Документация: https://docs.ollama.com/

Установите приложение для своей ОС, запустите Ollama и откройте терминал.

## 2. Загрузить быструю модель

Для начала можно попробовать компактную Qwen 3:

```bash
ollama pull qwen3:4b
```

Запустить интерактивный чат:

```bash
ollama run qwen3:4b
```

Если компьютер с небольшим объёмом оперативной памяти, попробуйте компактную модель:

```bash
ollama pull qwen2.5:3b
ollama run qwen2.5:3b
```

Каталог моделей: https://ollama.com/library

## 3. Проверить локальный API

Ollama обычно предоставляет API на локальном компьютере:

- API документация: https://docs.ollama.com/api
- По умолчанию локальный endpoint: http://localhost:11434

Не открывайте локальный endpoint наружу без необходимости. Не передавайте модели пароли, токены, личные данные или секреты.

## 4. Полезные настройки

- Для скорости используйте небольшие модели (3B–4B) и короткие промпты.
- Для сложных логических задач попробуйте модель крупнее, если хватает RAM/VRAM.
- Сравнивайте результат модели с условием; локальная модель может ошибаться.
